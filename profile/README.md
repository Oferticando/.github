# Oferticando

O Oferticando ajuda afiliados e lojistas a organizar, publicar e distribuir ofertas em vitrines digitais e canais como WhatsApp.

## Plataforma

O desenvolvimento do produto está centralizado no repositório privado `Oferticando/platform`, que reúne:

- site público;
- dashboard dos clientes;
- painel administrativo;
- API e automações.

Site: [oferticando.com.br](https://oferticando.com.br)
